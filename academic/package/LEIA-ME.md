# Frequência UFMG · entrega acadêmica

Abra `demo/README.md` para executar o produto. A demo usa apenas Python 3.11+,
SQLite local e uma página no navegador. Ela começa vazia; o botão **Usar dados
de exemplo** insere uma disciplina, presenças e uma prova fictícias. Em
**Ajustes**, é possível executar os testes e apagar a demo com confirmação.

Os relatórios estão em `relatorio/`; a saída da última execução dos testes está
em `evidencias/unittest.txt`. O roteiro `GUIA_APRESENTACAO.md` resume os blocos
de código que devem ser explicados na apresentação. O banco fornecido não
contém dados pessoais reais.
